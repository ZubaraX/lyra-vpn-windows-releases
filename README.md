# Lyra для Windows

Здесь публикуются готовые версии **Lyra для Windows** — VPN-клиента на ядре Xray, который пускает через VPN только нужные приложения.

Выберите программу — через VPN пойдёт весь её трафик **и всех процессов, которые она запускает**: помощников, обновлений, игр из лаунчера. Остальной компьютер, банки и российские сайты работают как обычно, без VPN.

## Как установить

1. Откройте [релизы](../../releases) и скачайте архив `lyra-windows-….zip` из последней версии.
2. Распакуйте его в любую папку, например `C:\Lyra`. Папку `core` рядом с `Lyra.exe` не удаляйте и не переносите: в ней ядро Xray.
3. Запустите `Lyra.exe` и разрешите запуск от администратора — без этого нельзя создать VPN-адаптер.

Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с программами без платной цифровой подписи. Некоторые антивирусы так же реагируют на `xray.exe`.

Устанавливать .NET не нужно — всё уже внутри. Нужна Windows 10 или 11 (64-бит).

## Быстрый старт

1. **Серверы** → «Подписка»: вставьте ссылку из личного кабинета или бота. Можно скопировать ссылку и нажать «Из буфера».
2. **Приложения** → «Добавить приложение»: отметьте программы из запущенных или установленных. Можно просто перетащить ярлык в окно Lyra.
3. Нажмите **«Подключить»**.

Во вкладке **«Соединения»** видно, какая программа куда подключена и идёт ли она через VPN.

## Что умеет

- **Приложения через VPN вместе со всей веткой процессов.** В правило входит сама программа, её папка и всё, что она запускает. Lyra запоминает новые программы ветки (например, игру из Steam на другом диске) и в следующий раз сразу пускает их через VPN.
- **Свой маршрут для каждого приложения:**
  - весь трафик через VPN;
  - через VPN, но российские сайты напрямую;
  - через свой сервер;
  - без VPN;
  - без интернета.
- **Остальные приложения** — напрямую или весь компьютер через VPN.
- Если приложение было открыто до подключения, Lyra сразу переподключает его соединения через VPN.
- **Протоколы:** VLESS (REALITY, XTLS Vision, XHTTP, gRPC, WS), VMess, Trojan, Shadowsocks, Hysteria2, JSON-конфиги Xray.
- **Подписки:** Remnawave, Marzban, 3x-ui и другие; показываются трафик и срок подписки.
- **Выбор и надёжность:** лучший сервер по пингу; проверка связи и автопереход на рабочий сервер без разрыва VPN.
- **Россия напрямую** и блокировка рекламы — базовая или по фильтру AdGuard DNS.
- **Аварийный выключатель:** без VPN приложения из списка не выходят в сеть.
- **Работа в фоне:** в трее, автозапуск вместе с Windows без запроса UAC.

## Где хранятся данные

- Настройки, серверы и список приложений — `%APPDATA%\Lyra`.
- Рабочие файлы ядра и журнал — `%LOCALAPPDATA%\Lyra`.

Чтобы удалить Lyra:

1. Выключите автозапуск в настройках.
2. Выйдите через значок в трее.
3. Удалите папку программы и обе папки выше.
